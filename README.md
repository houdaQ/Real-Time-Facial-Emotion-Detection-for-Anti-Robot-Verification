# Facial emotional detection

Facial emotional expression is an integral component of face recognition. While identifying emotions is an intuitive task for humans, replicating this capability through computer algorithms remains a significant challenge. However, driven by continuous advancements in computer vision and machine learning, detecting emotions in images and video streams has become increasingly viable.

This project proposes a facial expression recognition method based on Deep Neural Networks, specifically Convolutional Neural Networks (CNN). Following the normalization of facial images. To preserve the structural integrity and texture of the image, this extracted edge data is embedded into each feature map.
