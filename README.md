# Facial emotional detection

Facial emotional expression is an integral component of face recognition. While identifying emotions is an intuitive task for humans, replicating this capability through computer algorithms remains a significant challenge. However, driven by continuous advancements in computer vision and machine learning, detecting emotions in images and video streams has become increasingly viable.

This research proposes a facial expression recognition method based on Deep Neural Networks, specifically Convolutional Neural Networks (CNN), integrated with image edge detection. Following the normalization of facial images, edge information is extracted during the convolution process at each layer. To preserve the structural integrity and texture of the image, this extracted edge data is embedded into each feature map.

Throughout this study, several datasets were investigated to train and refine the expression recognition models. The primary objective of this paper is to analyze facial emotion detection and recognition using machine learning and deep learning algorithms. This work provides deeper insights into the technical frameworks of emotion recognition while highlighting the critical variables that impact its overall efficacy.
